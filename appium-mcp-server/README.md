# AutoGenesis Appium MCP

Installable stdio MCP runtime for BDD automation on iOS, Android, and macOS through Appium.

The runtime requires `autogenesis-agent-contract==2.2.0`. Launch it with an explicit configuration and business-project root:

```bash
autogenesis-appium-mcp --platform android --config /absolute/business/appium.json --project-root /absolute/business
```

Canonical Registry metadata is in [`server.json`](server.json). Generated-code confirmation requires the exact preview identity and digest plus explicit approval.
